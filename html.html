HTML 系统学习

HTML（HyperText Markup Language）是构建网页结构的标记语言。它用标签描述“这段内容是什么”——标题、段落、链接、图片、表单——而不是“它长什么样”。样式交给 CSS，交互交给 JavaScript。写好 HTML 的关键不是记住更多标签，而是理解语义、可访问性与文档结构。本模块覆盖从文档骨架到表单校验、语义化布局和 HTML5 API 的完整知识。

标记语言语义化HTML5 无障碍SEO
难度：入门 → 进阶 标准：HTML Living Standard 阅读时长：约 50 分钟

认识 HTML

HTML 不是编程语言，它没有变量、循环和逻辑判断。它是一套标记规则：用元素（element）包裹内容，告诉浏览器这部分是标题、那部分是列表。浏览器解析 HTML 后构建 DOM 树，再结合 CSS 计算样式、完成布局与绘制。

结构（HTML）

内容是什么：标题、段落、链接、表单、图片。

表现（CSS）

内容长什么样：颜色、字体、间距、布局、动画。

行为（JavaScript）

内容如何交互：点击、请求、校验、动态更新。

可访问性

屏幕阅读器、键盘用户、搜索引擎都依赖正确的语义。

浏览器渲染流程

  1. 解析 HTML：构建 DOM（Document Object Model）。
  2. 解析 CSS：构建 CSSOM。
  3. 合并：生成渲染树，只包含可见节点。
  4. 布局（Reflow）：计算每个盒子的位置与大小。
  5. 绘制（Paint）：填充像素；必要时合成（Composite）。

这也解释了许多性能建议：图片写宽高可减少布局抖动；脚本加 defer 可避免阻塞解析；语义化结构有助于浏览器与辅助技术理解页面。

文档结构

一个规范的 HTML5 文档包含文档类型声明、根元素、元信息区和内容区。浏览器对不完整 HTML 有容错机制，但不要依赖它。

index.htmlHTML5
<!DOCTYPE html>                         <!-- 标准模式，必须第一行 -->
<html lang="zh-CN">                     <!-- 根元素，lang 影响朗读与翻译 -->
<head>
    <meta charset="UTF-8">              <!-- 字符编码，尽早声明 -->
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <meta name="description" content="页面摘要，影响搜索结果">
    <meta name="author" content="呱瓜多米">
    <title>页面标题 · 站点名</title>

    <link rel="icon" href="favicon.ico">
    <link rel="stylesheet" href="style.css">
    <script src="app.js" defer></script>
</head>
<body>
    <h1>你好，HTML</h1>
    <p>这是页面内容。</p>
</body>
</html>
部分作用注意
<!DOCTYPE html>声明 HTML5 标准模式不写会进入怪异模式，盒模型等行为不同。
<html lang>页面语言中文用 zh-CN，影响屏幕阅读器发音。
<head>元信息、资源引用不直接显示在页面主体。
<meta charset>字符编码放在 head 最前面，避免乱码。
<meta viewport>移动端视口响应式页面必备。
<title>浏览器标签与搜索结果标题每个页面应唯一且具体。
<body>可见内容一个文档只有一个。
脚本加载：defer 与 async 普通 <script> 会阻塞 HTML 解析。加 defer 可延迟到文档解析完成后按顺序执行；async 则下载完立即执行，顺序不保证。依赖 DOM 的脚本通常用 defer。

元素与属性

元素通常由开始标签、内容和结束标签组成，例如 <p>文字</p>。有些元素没有内容和结束标签，称为空元素（void element），例如 <img>、<br>、<input>。

syntax.htmlHTML5
<!-- 普通元素 -->
<p class="intro" id="first">带属性的段落</p>

<!-- 空元素：没有结束标签 -->
<img src="a.png" alt="示例">
<br>
<hr>
<input type="text">
<meta charset="UTF-8">
<link rel="stylesheet" href="style.css">

<!-- 布尔属性：出现即为真，不需要 ="true" -->
<input type="checkbox" checked>
<button disabled>不可用</button>

<!-- 属性值用引号包裹，双引号最常见 -->
<a href="https://example.com" title="提示文字">链接</a>

<!-- 自定义数据属性：通过 JS 的 dataset 读取 -->
<div data-user-id="42" data-role="admin"></div>

<!-- 注释 -->
<!-- 这是注释，不会渲染 -->

全局属性

属性用途
id文档内唯一标识，可作锚点、label for 目标。
class可复用的类名，供 CSS/JS 选择。
style内联样式，优先级高，不利于维护，少量使用。
title悬停提示；不能替代可读标签。
lang元素内容语言，可局部覆盖。
hidden隐藏元素（仍可通过 CSS 覆盖）。
tabindex键盘 Tab 顺序；0 可聚焦，-1 可编程聚焦。
contenteditable让元素内容可编辑。
data-*自定义数据，JS 通过 element.dataset 访问。
role / aria-*ARIA 无障碍语义，优先使用原生语义标签。
块级与行内 传统上 div 是块级、span 是行内。HTML5 更强调内容类别（流内容、短语内容、段落内容等），但“块级元素不能嵌套在段落中”仍然成立：<p> 内不要放 <div> 或另一个 <p>。

文本内容

文本标签的选择应基于语义而非外观。<strong> 表示重要性，屏幕阅读器可能重读；<b> 只是视觉加粗。同理 <em> 表示强调语气，<i> 常用于术语、外语。

<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<!-- 标题按层级使用，不要为了字号跳级 -->

   <b>仅视觉加粗</b>，<i>术语或外语</i>。</p>

<p>行内代码 <code>console.log()</code>，
   键盘按键 <kbd>Ctrl</kbd> + <kbd>S</kbd>，
   程序输出 <samp>Hello</samp>，
   变量 <var>x</var>。</p>

<pre><code>保留   空格
和换行</code></pre>

<blockquote cite="https://example.com">
  这是一段引用，可以包含多个段落。
  <footer>— 出处</footer>
</blockquote>

字符实体

某些字符在 HTML 中有特殊含义，必须用实体表示：< 写成 &lt;，> 写成 &gt;，& 写成 &amp;。

实体显示说明
&lt;<小于号
&gt;>大于号
&amp;&和号
&quot;"双引号
&copy;©版权符号
&nbsp; 不换行空格（慎用）
&mdash;—长破折号
&rarr;→右箭头
空格与换行会被折叠 HTML 会把连续的空白字符合并成一个空格。不要用多个 &nbsp; 做排版；间距交给 CSS 的 margin / padding / gap。

链接

<a> 是超链接元素，核心属性是 href。链接可以指向外部页面、站内路径、页面锚点、邮箱、电话，甚至触发下载。

links.htmlHTML5
<!-- 外部绝对地址 -->
<a href="https://example.com">外部链接</a>

<!-- 新标签页打开；必须加 rel 防止安全与性能问题 -->
<a href="https://example.com" target="_blank"
   rel="noopener noreferrer">新标签打开</a>

<!-- 相对路径 -->
<a href="about.html">同目录页面</a>
<a href="../index.html">上一级页面</a>
<a href="/docs/intro.html">站点根路径</a>

<!-- 页面内锚点 -->
<a href="#section-id">跳到本节</a>
<h2 id="section-id">目标小节</h2>

<!-- 下载 -->
<a href="report.pdf" download="报告.pdf">下载报告</a>

<!-- 邮件与电话 -->
<a href="mailto:hi@example.com?subject=你好">发邮件</a>
<a href="tel:+8613800000000">拨打电话</a>

<!-- 链接包裹图片：记得给图片 alt -->
<a href="https://example.com">
  <img src="logo.png" alt="返回示例官网">
</a>
路径类型示例解析方式
绝对 URLhttps://example.com/a完整地址
根相对/images/logo.png从站点根目录开始
文档相对images/logo.png相对当前页面目录
父级相对../css/site.css向上一级目录
片段#top当前页面锚点
链接文字要能独立表意 不要写“点击这里”。屏幕阅读器会列出页面所有链接，<a>点击这里</a> 脱离上下文毫无意义。写“查看 Python 教程”更好。

图片与多媒体

图片元素 <img> 是空元素，src 指定资源，alt 提供替代文本。alt 不是可选项：图片加载失败时显示它，屏幕阅读器朗读它，搜索引擎也用它理解图片内容。

images.htmlHTML5
<!-- 基础用法：宽高可避免布局抖动（CLS） -->
<img src="photo.jpg" alt="海边日落，橙色的天空与海面"
     width="800" height="600" loading="lazy" decoding="async">

<!-- 装饰性图片：alt 留空，屏幕阅读器跳过 -->
<img src="divider.png" alt="">

<!-- 响应式：根据屏幕宽度选择不同资源 -->
<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w,
             photo-800.jpg 800w,
             photo-1600.jpg 1600w"
     sizes="(max-width: 600px) 100vw, 50vw"
     alt="响应式示例图片">

<!-- picture：格式回退或艺术方向 -->
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="带格式回退的图片">
</picture>

<!-- 图文说明 -->
<figure>
  <img src="chart.png" alt="2026 年访问量逐月上升的折线图">
  <figcaption>图 1：2026 年访问量趋势</figcaption>
</figure>

列表

列表分为无序列表 <ul>、有序列表 <ol> 和描述列表 <dl>。导航菜单、文章目录、步骤说明都应使用列表，而不是一堆 div。

lists.htmlHTML5
<ul>
  <li>苹果</li>
  <li>香蕉
    <ul>                 <!-- 嵌套列表放在 li 内部 -->
      <li>进口香蕉</li>
      <li>本地香蕉</li>
    </ul>
  </li>
</ul>

<ol>
  <li>打开终端</li>
  <li>创建虚拟环境</li>
  <li>安装依赖</li>
</ol>

<!-- 有序列表属性 -->
<ol type="A" start="3" reversed>
  <li>第三项</li>
  <li>第四项</li>
</ol>

<!-- 描述列表：术语 + 解释 -->
<dl>
  <dt>HTML</dt>
  <dd>描述网页结构的标记语言。</dd>
  <dt>CSS</dt>
  <dd>描述网页表现样式的语言。</dd>
</dl>

<!-- 导航通常用 nav + ul -->
<nav aria-label="主导航">
  <ul>
    <li><a href="/">首页</a></li>
    <li><a href="/docs">文档</a></li>
  </ul>
</nav>

表格

表格只用于展示二维数据，不要用来做页面布局。语义化的表格结构能帮助屏幕阅读器把单元格与表头关联起来。

table.htmlHTML5
<table>
  <caption>2026 年各语言学习人数</caption>
  <thead>
    <tr>
      <th scope="col">语言</th>
      <th scope="col">人数</th>
      <th scope="col">占比</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Python</th>
      <td>1,200</td>
      <td>40%</td>
    </tr>
    <tr>
      <th scope="row">C++</th>
      <td>900</td>
      <td>30%</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="1">合计</td>
      <td colspan="2">3,000</td>
    </tr>
  </tfoot>
</table>

<!-- 合并单元格 -->
<table>
  <tr>
    <th rowspan="2">姓名</th>
    <th colspan="2">成绩</th>
  </tr>
  <tr>
    <th>语文</th>
    <th>数学</th>
  </tr>
  <tr>
    <td>多米</td>
    <td>95</td>
    <td>98</td>
  </tr>
</table>
元素作用
caption表格标题，必须紧跟在 table 后。
thead / tbody / tfoot表头、主体、表尾分组。
tr行。
th表头单元格，默认加粗居中。
td普通数据单元格。
scope声明表头作用于行还是列（row / col）。
colspan / rowspan跨列 / 跨行合并。

语义化布局

HTML5 引入了一批语义标签，用它们替代满屏的 <div class="header">。语义化让代码更易读，也让辅助技术能识别页面区域。

layout.htmlHTML5
<body>
  <a class="skip-link" href="#main">跳到主要内容</a>

  <header>
    <h1>站点标题</h1>
    <nav aria-label="主导航">
      <ul>
        <li><a href="/">首页</a></li>
        <li><a href="/about">关于</a></li>
      </ul>
    </nav>
  </header>

  <main id="main">
    <article>
      <header>
        <h2>文章标题</h2>
        <p>发布于 <time datetime="2026-11-02">2026-11-02</time></p>
      </header>
      <p>文章正文……</p>
      <section aria-labelledby="comments-title">
        <h3 id="comments-title">评论</h3>
        <p>评论区内容</p>
      </section>
    </article>

    <aside aria-label="相关推荐">
      <h2>相关文章</h2>
      <ul><li><a href="/post/1">推荐文章</a></li></ul>
    </aside>
  </main>

  <footer>
    <p>© 2026 呱瓜多米</p>
  </footer>
</body>
标签含义使用建议
header页头或区块头部通常含标题、导航、搜索。
nav主要导航链接不是所有链接组都需要；一个页面可有多个。
main页面唯一主要内容每个页面只应有一个，且不应嵌套在 article 内。
article可独立分发的内容博客文章、新闻、论坛帖、卡片。
section按主题分组的内容通常应有标题；不要只为样式而用。
aside与主内容弱相关的补充侧栏、广告、相关推荐、注释。
footer页脚或区块尾部版权、联系方式、相关链接。
div / span无语义的通用容器没有更合适语义或纯为布局/样式时使用。
语义化不是“不能用 div” 当内容确实只是布局容器、没有独立语义时，div 是正确选择。关键是先问内容是什么，再选标签；不要为了“看起来语义化”滥用 section。

表单

表单是用户输入的主要入口。<form> 的 action 指定提交地址，method 指定 HTTP 方法（GET 参数在 URL，POST 在请求体）。每个可提交控件都需要 name，否则数据不会发送。

form.htmlHTML5
<form action="/submit" method="post">
  <fieldset>
    <legend>账号信息</legend>

    <!-- label 的 for 必须等于 input 的 id -->
    <label for="username">用户名</label>
    <input id="username" name="username" type="text"
           required minlength="3" maxlength="16"
           pattern="[A-Za-z0-9_]+"
           autocomplete="username"
           placeholder="3–16 位字母、数字或下划线">

    <label for="email">邮箱</label>
    <input id="email" name="email" type="email"
           required autocomplete="email">

    <label for="pwd">密码</label>
    <input id="pwd" name="password" type="password"
           required minlength="8" autocomplete="new-password">

    <label for="age">年龄</label>
    <input id="age" name="age" type="number"
           min="0" max="120" step="1">

    <label for="birth">生日</label>
    <input id="birth" name="birth" type="date">

    <label for="color">主题色</label>
    <input id="color" name="color" type="color">

    <label for="volume">音量</label>
    <input id="volume" name="volume" type="range"
           min="0" max="100" value="50">

    <label for="avatar">头像</label>
    <input id="avatar" name="avatar" type="file"
           accept="image/png,image/jpeg">
  </fieldset>

  <fieldset>
    <legend>偏好</legend>

    <!-- 单选：同一 name 为一组 -->
    <label><input type="radio" name="plan" value="free" checked> 免费版</label>
    <label><input type="radio" name="plan" value="pro"> 专业版</label>

    <!-- 多选 -->
    <label><input type="checkbox" name="tags" value="ai"> AI</label>
    <label><input type="checkbox" name="tags" value="web"> Web</label>

    <!-- 下拉 -->
    <label for="lang">语言</label>
    <select id="lang" name="lang">
      <optgroup label="后端">
        <option value="py">Python</option>
        <option value="java">Java</option>
      </optgroup>
      <optgroup label="前端">
        <option value="js">JavaScript</option>
      </optgroup>
    </select>

    <!-- 多行文本 -->
    <label for="bio">简介</label>
    <textarea id="bio" name="bio" rows="4" maxlength="200"></textarea>

    <!-- 输入建议 -->
    <label for="city">城市</label>
    <input id="city" name="city" list="cities">
    <datalist id="cities">
      <option value="北京">
      <option value="上海">
      <option value="深圳">
    </datalist>
  </fieldset>

  <button type="submit">提交</button>
  <button type="reset">重置</button>
  <button type="button" onclick="alert('仅前端操作')">普通按钮</button>
</form>

input 类型速览

type用途浏览器校验
text单行文本可配 pattern、长度限制
email邮箱格式检查
password密码（隐藏输入）长度限制
number数字min/max/step
tel电话不校验格式（国际差异大）
url网址URL 格式
date / time / datetime-local日期时间日期范围
checkbox / radio多选 / 单选required 对单选组有效

无障碍与 SEO

无障碍（Accessibility，常缩写 a11y）不是额外功能，而是正确使用 HTML 的自然结果。语义化 HTML 同时改善屏幕阅读器体验、键盘操作和搜索引擎理解。

核心检查清单

  • 语言：<html lang="zh-CN">，局部外语内容用 lang 覆盖。
  • 标题层级：按 h1 → h2 → h3 顺序，不跳级；一个页面通常一个 h1。
  • 图片 alt：信息性图片描述内容；装饰性图片写 alt=""。
  • 表单标签：每个控件都有关联的 label；不要只用 placeholder。
  • 键盘可用：链接和按钮本身可聚焦，不要用 div onclick 模拟按钮。
  • 可见焦点：不要用 CSS 去掉 :focus 轮廓而不提供替代样式。
  • 对比度：正文文字与背景对比度至少 4.5:1（大字号 3:1）。
  • 链接文字：避免“点击这里”，要能独立表意。
  • 跳过导航：提供“跳到主要内容”的 skip link。
  • 动态内容：用 aria-live 通知屏幕阅读器状态变化（谨慎使用）。
a11y.htmlHTML5
<!-- 跳过导航：键盘用户可快速到达主内容 -->
<a class="skip-link" href="#main">跳到主要内容</a>

<!-- 图标按钮必须有可访问名称 -->
<button aria-label="关闭对话框">
  <svg aria-hidden="true">...</svg>
</button>

<!-- 表单错误提示与控件关联 -->
<label for="email">邮箱</label>
<input id="email" type="email" aria-describedby="email-help"
       aria-invalid="true">
<p id="email-help">请输入有效的邮箱地址。</p>

<!-- 状态提示：不要滥用 role -->
<div role="status" aria-live="polite">保存成功</div>

<!-- 原生语义优先：这比 div + role="button" 更好 -->
<button type="button">原生按钮</button>

最佳实践

文档与结构

  • 始终写 <!DOCTYPE html>、lang、charset、viewport。
  • 每个页面一个 main，标题层级连续，不跳级。
  • 用语义标签表达结构；纯布局容器才用 div。
  • 标签正确嵌套并闭合；用 W3C Validator 检查。
  • 缩进统一（2 或 4 空格），属性值使用双引号。

性能

  • 图片写 width / height，减少布局偏移（CLS）。
  • 首屏外图片用 loading="lazy"；关键资源可 preload。
  • 脚本用 defer（有依赖）或 async（独立）。
  • 使用现代格式（WebP/AVIF）并提供回退；响应式图片用 srcset。
  • 减少 DOM 深度与不必要的嵌套。

维护性

  • class 命名表达含义（可采用 BEM 等约定），不要用 red、left 这类表现性名字。
  • 交互控件用 button / a 原生元素，保留键盘与辅助技术支持。
  • 样式放 CSS 文件，行为放 JS 文件，HTML 保持结构清晰。
  • 表单控件必须有 label、name、合理的 autocomplete。
  • 为动态内容准备加载、空状态、错误状态。
一个可靠的起步模板 doctype + html[lang] + head[charset, viewport, title, description] + header/nav + main + footer。先把结构和内容写正确，再叠加 CSS 与 JS。
