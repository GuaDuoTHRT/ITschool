认识 Python

Python 由 Guido van Rossum 于 1991 年发布，名字来自喜剧团体 Monty Python 而非蟒蛇。它的设计哲学写在 import this 输出的《Python 之禅》中：优美胜于丑陋，明确胜于隐晦，简单胜于复杂。这些原则直接影响了它的语法：用缩进代替花括号、用鸭子类型代替强制接口、用内置容器覆盖大部分日常需求。

执行原理：不是“纯解释”

以最常用的 CPython 为例，执行 .py 文件时并不是逐字符解释。它先把源码编译成字节码（bytecode），再由 Python 虚拟机逐条执行；导入的模块还会生成 __pycache__/*.pyc 缓存以加速后续加载。所以准确说法是：先编译为字节码，再由解释器执行。

解释型 · 跨平台

同一份源码可在 Windows / macOS / Linux 运行，只要安装对应解释器。

动态类型

变量不绑定类型，运行时才确定对象类型；灵活但需要测试与类型注解兜底。

自动内存管理

引用计数 + 循环垃圾回收，无需手动 free，但要注意循环引用与内存占用。

电池齐全

标准库覆盖文件、网络、JSON、日期、正则、并发等，第三方包生态更是庞大。

在条件判断中，以下值被视为假：None、False、数字 0 / 0.0、空字符串 ""、空列表 []、空元组 ()、空字典 {}、空集合 set()。其余对象一般为真。

易错点：== 与 is 不是一回事 == 比较值是否相等（调用 __eq__）；is 比较是否是同一个对象。判断 None 应写 x is None，不要写 x == None。

最经典的 Python 陷阱：可变默认参数 默认值在函数定义时只求值一次，之后所有调用共享同一个对象。
错误示例PYTHON

    bucket.append(item)

def append_safe(item, bucket=None): # 正确写法
    if bucket is None:

    bucket.append(item)

面向对象

Python 的类支持封装、继承、多态，但没有 private 关键字，靠命名约定表达可见性。它更强调“鸭子类型”：只要对象有需要的方法，就可以当作某种类型使用。

oop.pyPYTHON
class Animal:
    kind = "动物"                 # 类属性，所有实例共享

    def __init__(self, name: str):
        self.name = name          # 实例属性
        self._secret = "内部"      # 单下划线：约定为受保护
        self.__hidden = "私有"     # 双下划线：名称改写为 _类名__hidden

    def speak(self) -> str:
        return "..."

    def __str__(self) -> str:      # print() 时调用
        return f"<{self.kind}:{self.name}>"

    def __repr__(self) -> str:     # 调试表示
        return f"Animal(name={self.name!r})"

    def __len__(self) -> int:      # len(obj)
        return len(self.name)

class Dog(Animal):
    def __init__(self, name, breed="中华田园犬"):
        super().__init__(name)     # 调用父类构造
        self.breed = breed

    def speak(self) -> str:        # 重写
        return f"{self.name}：汪汪！"

class Cat(Animal):
    def speak(self) -> str:
        return f"{self.name}：喵～"

# 多态：同一调用，不同表现
for animal in [Dog("旺财"), Cat("咪咪")]:
    print(animal.speak())

# isinstance / issubclass
print(isinstance(Dog("旺财"), Animal))   # True
print(issubclass(Cat, Animal))            # True

实例方法、类方法、静态方法与属性

methods.pyPYTHON
class Temperature:
    unit = "C"

    def __init__(self, celsius):
        self._celsius = celsius

    def to_fahrenheit(self):          # 实例方法：self
        return self._celsius * 9 / 5 + 32

    @classmethod
    def from_fahrenheit(cls, f):      # 类方法：cls，常用于替代构造
        return cls((f - 32) * 5 / 9)

    @staticmethod
    def is_valid(c):                  # 静态方法：不需要 self/cls
        return c >= -273.15

    @property
    def celsius(self):                # 属性：像访问字段一样调用方法
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("低于绝对零度")
        self._celsius = value

t = Temperature(100)
print(t.to_fahrenheit())   # 212.0
print(t.celsius)           # 100
t.celsius = 0              # 触发 setter

异常处理

Python 用异常表示错误，而不是返回错误码。异常类都继承自 BaseException，日常捕获的应该是 Exception 的子类。

exceptions.pyPYTHON
try:
    n = int(input("输入数字："))
    result = 10 / n
except ValueError:
    print("输入的不是数字")
except ZeroDivisionError as e:
    print(f"不能除以零：{e}")
except (TypeError, KeyError) as e:   # 多个异常合并捕获
    print(f"类型或键错误：{e}")
else:
    print("没有异常时才执行：", result)
finally:
    print("无论是否异常都会执行，常用于释放资源")

# 主动抛出
def set_age(age):

class BusinessError(Exception):
    """业务异常基类。"""

class InsufficientBalance(BusinessError):
    def __init__(self, balance, amount):
        super().__init__(f"余额 {balance} 不足以支付 {amount}")
        self.balance = balance
        self.amount = amount

# 异常链：保留原始错误上下文
try:
    int("abc")
except ValueError as e:
    raise BusinessError("参数解析失败") from e
异常常见原因
ValueError类型正确但值不合法，如 int("abc")
TypeError类型不匹配，如 "a" + 1
KeyError字典键不存在
IndexError序列下标越界
AttributeError对象没有该属性
FileNotFoundError文件不存在
ZeroDivisionError除数为零
不要裸捕获 except: 或 except Exception: pass 会吞掉所有错误，让 Bug 难以定位。只捕获你真正能处理的异常，并记录日志或重新抛出。

迭代器与生成器

可迭代对象（iterable）实现了 __iter__；迭代器（iterator）同时实现 __iter__ 和 __next__。for 循环的本质就是不断调用 next()，直到抛出 StopIteration。

iterators.pyPYTHON
nums = [1, 2, 3]
it = iter(nums)
print(next(it))   # 1
print(next(it))   # 2

# 生成器函数：用 yield 惰性产出值
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

for num in fib(8):
    print(num, end=" ")     # 0 1 1 2 3 5 8 13

# 生成器表达式：惰性，不一次性占用内存
squares = (x * x for x in range(1_000_000))
print(next(squares))        # 0
print(sum(squares))         # 可继续消费剩余元素

# 自定义迭代器
class Countdown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        self.current -= 1
        return self.current + 1

# itertools：强大的迭代工具
import itertools
print(list(itertools.islice(itertools.count(10, 2), 5)))  # [10,12,14,16,18]
print(list(itertools.chain([1, 2], [3, 4])))              # [1,2,3,4]
print(list(itertools.product("AB", repeat=2)))
什么时候用生成器 数据量大、只需单次遍历、或来源是流式数据（日志、网络、数据库游标）时，用生成器可以显著降低内存。代价是只能消费一次，且不能随机访问。

装饰器

装饰器是“接收函数并返回新函数”的高阶函数，用 @ 语法糖应用。理解它需要先理解两件事：函数是一等对象、闭包可以保存状态。

decorators.pyPYTHON
import time
import functools

# 基础装饰器：不改变原函数签名地增加行为
def timer(func):
    @functools.wraps(func)          # 保留 __name__、__doc__ 等元信息
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f"{func.__name__} 耗时 {elapsed:.4f}s")
        return result
    return wrapper

@timer
def slow_task(n):
    time.sleep(0.1)
    return n * 2

print(slow_task(10))
# 等价于：slow_task = timer(slow_task)

# 带参数的装饰器：多包一层
def retry(times=3, delay=0.5):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_error = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_error = e
                    time.sleep(delay)
            raise last_error
        return wrapper
    return decorator

@retry(times=3)
def fetch_data():
    ...

# 缓存：相同参数直接返回结果
@functools.lru_cache(maxsize=128)
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

# 类装饰器
class CountCalls:
    def __init__(self, func):
        self.func = func
        self.calls = 0
    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)
务必使用 functools.wraps 否则被装饰函数的 __name__ 会变成 wrapper，影响日志、文档和调试。

并发模型

CPython 有 GIL（全局解释器锁），同一时刻只有一个线程执行 Python 字节码。因此多线程不适合 CPU 密集任务，但非常适合 I/O 密集任务（等待网络、磁盘时 GIL 会释放）。

模型适用场景特点
threadingI/O 密集、需要共享内存受 GIL 限制，CPU 密集无法并行；需处理竞态。
multiprocessingCPU 密集独立进程、独立解释器，可真正多核；进程间通信有开销。
asyncio高并发 I/O单线程事件循环，协程切换开销小；需要全链路异步库。
concurrency.pyPYTHON
# 多线程：适合下载、请求等 I/O 等待
import threading

urls = ["https://example.com/a", "https://example.com/b"]

def download(url):
    print("下载", url)

threads = [threading.Thread(target=download, args=(u,)) for u in urls]
for t in threads:
    t.start()
for t in threads:
    t.join()             # 等待全部结束

# 多进程：适合计算密集型
from multiprocessing import Pool

def cpu_task(n):
    return sum(i * i for i in range(n))

if __name__ == "__main__":
    with Pool() as pool:
        print(pool.map(cpu_task, [10**6, 10**6]))

# 协程：高并发 I/O
import asyncio

async def fetch(name, delay):
    await asyncio.sleep(delay)
    return f"{name} 完成"

async def main():
    results = await asyncio.gather(
        fetch("A", 1), fetch("B", 2), fetch("C", 1)
    )
    print(results)

asyncio.run(main())
选择顺序 先问瓶颈是 CPU 还是 I/O。I/O 密集优先 asyncio 或用线程池；CPU 密集用多进程，或把热点写成 C/C++/Rust 扩展、NumPy 向量化。

PEP 8 与可读性要点

  • 每级缩进 4 个空格；运算符两侧加空格；逗号后加空格。
  • 函数尽量短小，只做一件事；命名要表达意图。
  • 用 pathlib 处理路径，用 f-string 格式化文本。
  • 异常信息要包含上下文；日志用 logging 而非到处 print。
  • 公开函数写 docstring；复杂逻辑写测试而不是长注释。
