C++ 系统学习

C++ 是一门编译型、静态类型、多范式的系统级编程语言。它同时支持面向过程、面向对象、泛型编程和函数式风格，并以“零成本抽象”为设计信条：你不使用的高级特性不会带来运行时代价。C++ 广泛用于游戏引擎、操作系统、浏览器、数据库、高频交易和嵌入式系统。本模块从编译模型讲到现代 C++ 的资源管理，帮助你建立正确的心智模型。

编译型静态类型RAII STL零成本抽象
难度：入门 → 高级 建议标准：C++17 / C++20 阅读时长：约 60 分钟

认识 C++

C++ 由 Bjarne Stroustrup 在 C 语言基础上发展而来，最初名为 “C with Classes”。它保留了 C 的底层控制能力，又加入了类、模板、异常、命名空间等抽象机制。今天的 C++ 每隔三年发布一个新标准（C++11/14/17/20/23），现代 C++ 与早期的 C++98 在写法上已有巨大差异。

高性能

直接编译为机器码，无虚拟机与垃圾回收，可精确控制内存布局与缓存。

零成本抽象

模板、内联、RAII 等抽象在编译期展开，运行时开销可预测。

多范式

过程式、OOP、泛型、函数式可以混合使用，按问题选择工具。

复杂度高

手动管理生命周期、未定义行为、编译链接模型都需要系统学习。

从源码到可执行文件

理解 C++ 的编译模型，能解释大量“为什么”：为什么需要头文件、为什么会出现重复定义、为什么模板要写在头文件里。一次构建通常分为四个阶段：

  1. 预处理：展开 #include、处理 #define 与条件编译，生成翻译单元。
  2. 编译：把每个 .cpp 翻译成汇编，再汇编为目标文件 .o / .obj。
  3. 链接：把多个目标文件和库合并，解析符号引用，生成可执行文件。
  4. 加载运行：操作系统加载器把程序映射进内存并跳转到入口。
头文件不是“库” 头文件通常只放声明（函数原型、类定义、模板），实现放在 .cpp。多个源文件 #include 同一个头文件时，头文件内容会在每个翻译单元中各出现一次，所以需要 include guard 防止同一单元内重复展开。

常见选项作用
-std=c++17选择语言标准。
-Wall -Wextra开启常用警告，强烈建议始终开启。
-O2 / -O3优化级别；调试时用 -O0 -g。
-I path添加头文件搜索目录。
-L path -lname添加库目录并链接库。
-fsanitize=address,undefined启用 AddressSanitizer 与 UBSan 检测内存/未定义行为。
不要在头文件写 using namespace std; 头文件会被很多源文件包含，using namespace std; 会把整个标准库名字注入每个使用者的全局命名空间，极易造成命名冲突。源文件内小范围使用可以接受，更推荐显式写 std::。

#include <cstdint>
#include <string>

int main() {
    int a = 10;
    double pi = 3.14159;
    char ch = 'A';
    bool flag = true;
    std::string name = "多米";

    int x1 = 1;        // 拷贝初始化

窄化转换与有符号溢出 有符号整数溢出在 C++ 中是未定义行为，不是自动回绕。无符号整数溢出则按模 2ⁿ 回绕。浮点转整数超出范围同样是未定义行为。

引用与指针

引用是对象的别名，指针是保存地址的对象。两者都能避免拷贝，但语义和使用场景不同。

特性引用 T&指针 T*
是否必须初始化是否
能否为空否（合法引用总指向对象）是（nullptr）
能否重新绑定否是
是否可做算术否是（数组/缓冲区）
语法像普通变量需要 * / &
典型用途函数参数、返回值、别名可空关系、动态内存、底层操作

内存管理与 RAII

C++ 没有垃圾回收。对象要么在栈上（自动生命周期），要么在堆上（手动或智能指针管理）。现代 C++ 的核心思想是 RAII：Resource Acquisition Is Initialization，把资源生命周期绑定到对象生命周期，构造时获取、析构时释放。

区域分配方式生命周期特点
栈 stack局部变量、std::vector 对象本身作用域结束自动销毁分配极快、容量有限
堆 heapnew、malloc、容器内部缓冲手动 / 智能指针容量大、分配较慢、易泄漏
静态区全局变量、static程序运行期间注意初始化顺序问题

#include <memory>
#include <iostream>
#include <cstdio>

// 独占所有权：不能拷贝，只能移动
auto p = std::make_unique<int>(42);
std::cout << *p << '\n';
// auto p2 = p;              // 错误：unique_ptr 不可拷贝
auto p3 = std::move(p);      // 转移所有权，p 变为 nullptr

// 共享所有权：引用计数归零时释放
auto sp1 = std::make_shared<std::string>("hello");

}

// 循环引用：两个 shared_ptr 互相持有 → 永不释放

    std::shared_ptr<Node> next;
    // std::weak_ptr<Node> prev;  // 反向边用 weak_ptr 打破循环
};

// 自定义删除器：管理文件、锁等非内存资源
auto deleter = [](FILE* f) { if (f) fclose(f); };
std::unique_ptr<FILE, decltype(deleter)> file(fopen("a.txt", "r"), deleter);

Rule of 0 / 3 / 5 与移动语义

如果一个类需要自定义析构函数、拷贝构造、拷贝赋值中的任何一个，通常三个都需要（Rule of 3）。C++11 加入移动构造与移动赋值后扩展为 Rule of 5。但最好的做法是 Rule of 0：用 std::string、std::vector、智能指针等 RAII 成员，让编译器自动生成正确的特殊成员函数。

move.cppC++17
#include <utility>
#include <vector>
#include <string>
#include <algorithm>
#include <cstddef>

class Buffer {
public:
    explicit Buffer(std::size_t n) : data_(new char[n]), size_(n) {}

    ~Buffer() { delete[] data_; }

    // 拷贝构造：深拷贝
    Buffer(const Buffer& other)
        : data_(new char[other.size_]), size_(other.size_) {
        std::copy(other.data_, other.data_ + size_, data_);
    }

    // 移动构造：偷走资源，把源对象置空
    Buffer(Buffer&& other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;
        other.size_ = 0;
    }

    // 拷贝赋值（copy-and-swap 惯用法）
    Buffer& operator=(const Buffer& other) {
        Buffer tmp(other);
        swap(tmp);
        return *this;
    }

    // 移动赋值
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    void swap(Buffer& other) noexcept {
        std::swap(data_, other.data_);
        std::swap(size_, other.size_);
    }

private:
    char* data_;
    std::size_t size_;
};

// std::move 只是把左值转换为右值引用，本身不移动任何东西
std::string a = "hello";
std::string b = std::move(a);   // 之后 a 处于有效但未指定状态
// 不要再使用 a 的值

std::vector<std::string> v;
v.push_back(std::string("world"));  // 临时对象被移动
v.emplace_back("直接构造");           // 原地构造，少一次移动
默认用 unique_ptr 和值语义 优先让对象直接持有资源（栈对象、std::vector），需要多态时用 unique_ptr<Base>。只在确实共享所有权时用 shared_ptr，并警惕循环引用。

流程控制

control.cppC++17
#include <iostream>
#include <vector>
#include <map>

int main() {
    int score = 85;
    if (score >= 90) {
        std::cout << "A\n";
    } else if (score >= 80) {
        std::cout << "B\n";
    } else {
        std::cout << "C\n";
    }

    // switch：case 后要 break，否则会贯穿（fallthrough）
    int day = 3;
    switch (day) {
        case 1:
        case 2:
            std::cout << "工作日\n";
            break;
        case 6:
        case 7:
            std::cout << "周末\n";
            break;
        default:
            std::cout << "其他\n";
    }

    // for / while / do-while
    for (int i = 0; i < 5; ++i) {
        if (i == 3) continue;
        std::cout << i << ' ';
    }

    int n = 3;
    while (n > 0) { --n; }

    do {
        std::cout << "至少执行一次\n";
    } while (false);

    // 范围 for：只读用 const auto&，修改用 auto&
    std::vector<int> nums = {1, 2, 3};
    for (const auto& x : nums) {
        std::cout << x << ' ';
    }
    for (auto& x : nums) {
        x *= 2;                 // 修改元素
    }

    // 结构化绑定（C++17）
    for (const auto& [key, value] : std::map<std::string, int>{ {"a", 1} }) {
        std::cout << key << '=' << value;
    }
    return 0;
}
范围 for 中不要修改容器结构 在范围 for 中向 vector 添加/删除元素可能导致迭代器失效。需要增删时用下标循环或先收集操作再统一执行。

类与对象

C++ 的类把数据和行为封装在一起。struct 与 class 的唯一区别是默认访问权限：struct 默认 public，class 默认 private。

class.cppC++17
#include <iostream>
#include <string>
#include <utility>

class Animal {
public:
    // explicit 禁止隐式转换
    explicit Animal(std::string name) : name_(std::move(name)) {}

    // 多态基类必须虚析构，否则 delete 基类指针是 UB
    virtual ~Animal() = default;

    // virtual 启用动态绑定；const 表示不修改对象
    virtual std::string speak() const { return "..."; }

    // 纯虚函数 → 抽象类，不能直接实例化
    // virtual std::string kind() const = 0;

    const std::string& name() const { return name_; }

protected:
    std::string name_;
};

class Dog : public Animal {
public:
    using Animal::Animal;      // 继承构造函数

    std::string speak() const override {   // override 让编译器检查签名
        return name_ + "：汪汪！";
    }
};

class Cat final : public Animal {           // final 禁止再被继承
public:
    using Animal::Animal;
    std::string speak() const override {
        return name_ + "：喵～";
    }
};

int main() {
    Dog dog("旺财");
    Cat cat("咪咪");
    std::cout << dog.speak() << '\n';     // 静态绑定

    Animal* a = &dog;                        // 父类指针指向子类
    std::cout << a->speak() << '\n';       // 动态绑定 → 汪汪

    Animal& ref = cat;                       // 引用也支持多态
    std::cout << ref.speak() << '\n';       // 喵～

    // delete a;  // 若不是虚析构，行为未定义
    return 0;
}

构造函数、静态成员与运算符重载

members.cppC++17
#include <iostream>

class Counter {
public:
    static int created;                 // 静态成员：属于类，不属于对象

    Counter() : value_(0) { ++created; }

    // 委托构造
    explicit Counter(int v) : Counter() { value_ = v; }

    // 成员初始化顺序 = 声明顺序，不是列表书写顺序
    // 因此列表顺序最好与声明顺序一致

    void increment() { ++value_; }
    int value() const { return value_; } // const 成员函数不能修改成员

    // 友元：允许外部函数访问私有成员
    friend std::ostream& operator<<(std::ostream& os, const Counter& c);

    // 运算符重载：让自定义类型像内置类型一样使用
    Counter& operator+=(int n) {
        value_ += n;
        return *this;
    }
    bool operator==(const Counter& other) const {
        return value_ == other.value_;
    }

private:
    int value_;
};
int Counter::created = 0;               // 静态成员需在类外定义

std::ostream& operator<<(std::ostream& os, const Counter& c) {
    return os << "Counter(" << c.value_ << ")";
}

zoo.push_back(std::make_unique<Dog>("旺财"));
for (const auto& animal : zoo) {
    std::cout << animal->speak() << '\n';
}
多态基类必须有虚析构 通过基类指针 delete 派生类对象时，如果析构函数不是 virtual，只会调用基类析构，派生类资源泄漏，行为未定义。经验法则：只要类有虚函数，就给它虚析构。

STL 标准库

STL（Standard Template Library）由容器、迭代器、算法、函数对象组成。它的设计把“数据存储”和“数据处理”解耦：算法通过迭代器操作容器，因此一套 std::sort 可以用于所有随机访问容器。

常用容器

容器底层结构查找插入/删除说明
std::vector连续动态数组O(1) 下标尾部均摊 O(1)，中间 O(n)默认首选，缓存友好
std::array固定数组O(1)不支持增删大小编译期确定
std::deque分段连续O(1)头尾 O(1)双端队列

std::set红黑树O(log n)O(log n)去重且有序
std::stack / queue容器适配器——后进先出 / 先进先出

vector.cppC++17
#include <vector>
#include <iostream>
#include <algorithm>
#include <functional>

std::vector<int> v = {3, 1, 4, 1, 5};

v.push_back(9);
v.emplace_back(2);           // 原地构造，通常更高效
v.reserve(100);              // 预分配容量，避免多次扩容
std::cout << v.size() << ' ' << v.capacity() << '\n';

v[0] = 10;                   // 不做越界检查
v.at(0) = 11;                // 越界抛 std::out_of_range

std::sort(v.begin(), v.end());                 // 升序
std::sort(v.begin(), v.end(), std::greater<>{}); // 降序

// erase-remove 惯用法：删除所有值为 1 的元素
v.erase(std::remove(v.begin(), v.end(), 1), v.end());

// 遍历
for (const auto& x : v) std::cout << x << ' ';
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it;
}

#include <map>

#include <numeric>

std::map<std::string, int> ordered;        // 键有序，红黑树

fast["banana"] = 5;

    std::cout << it->second << '\n';

// 结构化绑定遍历
for (const auto& [key, value] : fast) {
    std::cout << key << " -> " << value << '\n';
}

// 常用算法
std::vector<int> nums = {5, 2, 8, 1, 9};

auto it = std::find(nums.begin(), nums.end(), 8);
bool exists = it != nums.end();

int total = std::accumulate(nums.begin(), nums.end(), 0);
int maxVal = *std::max_element(nums.begin(), nums.end());

std::vector<int> doubled(nums.size());
std::transform(nums.begin(), nums.end(), doubled.begin(),
               [](int x) { return x * 2; });

bool anyEven = std::any_of(nums.begin(), nums.end(),
                           [](int x) { return x % 2 == 0; });

std::sort(nums.begin(), nums.end());
bool found = std::binary_search(nums.begin(), nums.end(), 8);

// lower_bound：第一个 >= 的位置（要求有序）
auto lb = std::lower_bound(nums.begin(), nums.end(), 5);
优先 vector，谨慎 list 现代 CPU 的缓存对连续内存极其友好。std::list 虽然“插入 O(1)”，但节点分散、每次分配有开销，实际往往比 vector 慢。除非有明确的中间稳定插入/删除需求，否则用 vector。

模板与泛型

模板让代码在编译期针对不同类型实例化，实现零成本泛型。函数模板、类模板是 STL 的基础；C++20 引入 Concepts，让模板约束更清晰、报错更友好。

template.cppC++20
#include <iostream>
#include <vector>
#include <concepts>

// 函数模板
template <typename T>
T maxOf(T a, T b) {
    return a > b ? a : b;
}

// 多个类型参数 + 返回值推导
template <typename A, typename B>
auto add(A a, B b) {
    return a + b;
}

// 类模板
template <typename T, std::size_t N>
class FixedArray {
public:
    T& operator[](std::size_t i) { return data_[i]; }
    constexpr std::size_t size() const { return N; }
private:
    T data_[N]{};
};

// C++20 Concepts：约束类型必须支持加法
template <typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

template <Addable T>
T twice(T x) { return x + x; }

// 变参模板（C++11）
template <typename... Args>
void printAll(const Args&... args) {
    ((std::cout << args << ' '), ...);   // C++17 折叠表达式
}

int main() {
    std::cout << maxOf(3, 7) << '\n';
    std::cout << maxOf(2.5, 1.5) << '\n';
    std::cout << add(1, 2.5) << '\n';

    FixedArray<int, 5> arr;
    arr[0] = 42;
    std::cout << arr.size() << '\n';

    std::cout << twice(21) << '\n';
    printAll(1, "hello", 3.14);
    return 0;
}
模板定义通常要放在头文件 编译器在实例化模板时需要看到完整定义，因此模板的函数体一般写在 .h / .hpp 中，而不是 .cpp。否则链接阶段会出现“找不到符号”。

现代 C++

C++11 是一次里程碑式更新，之后的 C++14/17/20 不断让代码更安全、更简洁。以下是最常用的现代特性。

Lambda 表达式

lambda.cppC++17
#include <iostream>
#include <vector>
#include <algorithm>

int threshold = 10;

// [捕获列表](参数) -> 返回类型 { 函数体 }
auto square = [](int x) { return x * x; };
std::cout << square(5) << '\n';

// 捕获方式
auto byValue = [threshold](int x) { return x > threshold; };  // 值捕获，拷贝一份
auto byRef = [&threshold](int x) { return x > threshold; };    // 引用捕获
auto allByValue = [=](int x) { return x + threshold; };
auto allByRef = [&](int x) { return x + threshold; };
auto init = [n = 5](int x) { return x + n; };                  // 初始化捕获（C++14）

// mutable：允许修改值捕获的副本
auto counter = [count = 0]() mutable { return ++count; };

// 泛型 lambda（C++14）
auto print = [](const auto& value) { std::cout << value << '\n'; };

std::vector<int> v = {3, 1, 4, 1, 5};
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;      // 降序
});
std::for_each(v.begin(), v.end(), [](int x) {
    std::cout << x << ' ';
});
引用捕获与生命周期 Lambda 若在捕获的引用对象销毁后被调用，就是悬垂引用。异步任务、回调、线程中尤其要注意：优先值捕获，或确保对象生命周期覆盖 lambda。

调试与检查工具

  • 编译警告：始终开启 -Wall -Wextra -Wpedantic，很多 Bug 在编译期就能发现。
  • ASan / UBSan：-fsanitize=address,undefined 检测越界、释放后使用、未定义行为。
  • gdb / lldb：断点、单步、查看调用栈；编译时加 -g 保留调试信息。
  • Valgrind：Linux 下检测内存泄漏与非法访问。
  • clang-tidy / cppcheck：静态分析，发现风格与潜在缺陷。

未定义行为与常见陷阱

陷阱后果 / 正确做法
未初始化变量读取的是不确定值；变量尽量在定义时初始化。
数组越界UB；用 std::vector::at 或边界检查。
有符号整数溢出UB；改用无符号或更大类型，或做前置检查。
解引用空指针崩溃 / UB；使用前判断或使用引用。
悬垂指针 / 引用对象销毁后仍访问；注意生命周期，不要返回局部引用。
new / delete 不配对泄漏或双重释放；用 RAII / 智能指针。
new[] 配 deleteUB；必须 delete[]。
迭代器失效容器扩容或删除后继续使用旧迭代器。
对象切片值拷贝丢失派生部分；多态用指针/引用。
多态基类无虚析构delete 基类指针时 UB。
头文件写 using namespace std;命名冲突；使用 std:: 前缀。
浮点直接用 ==精度误差；用 epsilon 或 std::abs(a-b) < eps。
宏滥用无类型检查、副作用；优先 constexpr / inline 函数。
现代 C++ 的实践清单 用值语义与 RAII；默认 unique_ptr；只用 const 引用传大对象；开启全部警告与 sanitizer；避免裸 new/delete；多态基类加虚析构；容器优先 vector；用 std::string_view 传只读字符串；用 std::optional 代替魔法值。
