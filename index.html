// 02 · LEARNING PROTOCOL

推荐学习路径

不要只读不写。每学完一个小节，立刻改动示例、运行、制造错误并修复，这是形成肌肉记忆最快的方式。

STEP 01

选择入口

零基础建议从 Python 或 HTML 开始；想理解底层与性能选 C++；面向企业后端选 Java；写文档随时补 Markdown。

STEP 02

按目录推进

左侧目录按知识依赖排序。先读概念，再看代码，最后看易错点与对比表；遇到不懂的术语回到前一节。

STEP 03

动手验证

复制示例到本地运行，修改参数、故意触发错误、阅读报错信息。能解释“为什么错”才算真正掌握。

STEP 04

构建作品

用一个真实小项目串联知识点：命令行工具、爬虫、网页、API 服务。作品比笔记更能证明理解。

// 03 · SYSTEM PROPERTIES

系统特性

为长时间阅读与反复查阅而设计：结构统一、重点突出、离线可用。

DETAILED EXPLANATION

不止给代码：每个知识点都解释“是什么、为什么、什么时候用、常见误区”。

RUNNABLE EXAMPLES

示例尽量可直接运行，并标注输出或预期结果，方便对照验证。

COMPARISON TABLES

用表格对比相似概念：引用与指针、重载与重写、ArrayList 与 LinkedList。

PITFALL ALERTS

易错点、未定义行为、平台差异单独提示，减少踩坑成本。

OFFLINE FIRST

纯 HTML + 内联 CSS，无外部字体、脚本与网络请求，双击即用。

CONSISTENT UX

五个模块统一导航、配色与排版，切换语言不打断阅读节奏。
