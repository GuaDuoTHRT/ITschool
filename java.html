Java 系统学习

Java 是一门面向对象、静态类型、编译与解释混合执行的通用语言。源码先编译成与平台无关的字节码，再由 JVM 在各平台上运行，这就是“一次编写，到处运行”的基础。Java 拥有成熟的企业生态（Spring、Maven、微服务）和庞大的 Android 开发基础。本模块从 JVM 原理讲到集合、泛型、并发与现代语法，帮助你写出正确且易维护的 Java 代码。

难度：入门 → 进阶 建议版本：Java 17 / 21 LTS 阅读时长：约 55 分钟

平台与运行原理

Java 1995 年由 Sun 公司发布，现由 Oracle 维护。它最重要的设计是字节码 + 虚拟机：编译器 javac 不生成机器码，而是生成 .class 字节码；不同操作系统上安装各自的 JVM，由 JVM 负责把字节码翻译成当前平台的机器指令。

面向对象

Java 的面向对象围绕类与对象展开。类描述状态（字段）与行为（方法），对象是类的实例。三大特性是封装、继承、多态。

Oop.javaJAVA
class Animal {
    // 封装：字段私有，通过方法访问
    private String name;
    protected int age;

    Animal(String name) {          // 构造方法，与类同名，无返回值
        this.name = name;          // this 区分字段与参数
    }

    public String getName() { return name; }
    public void setName(String name) {
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("名字不能为空");
        }
        this.name = name;
    }

    public String speak() {
        return "...";
    }

    @Override
    public String toString() {
        return "Animal(" + name + ")";
    }
}

class Dog extends Animal {         // 继承：Java 类只能单继承
    private final String breed;

    Dog(String name, String breed) {
        super(name);               // 调用父类构造，必须是第一条语句
        this.breed = breed;
    }

    @Override                      // 编译期检查是否正确重写
    public String speak() {        // 方法重写：动态绑定
        return getName() + "：汪汪！";
    }

    public String getBreed() { return breed; }
}

class Cat extends Animal {
    Cat(String name) { super(name); }

    @Override
    public String speak() {
        return getName() + "：喵～";
    }
}

public class Oop {
    public static void main(String[] args) {
        Animal a = new Dog("旺财", "田园犬");  // 向上转型，多态
        System.out.println(a.speak());           // 旺财：汪汪！

        if (a instanceof Dog dog) {              // 模式匹配（Java 16+）
            System.out.println(dog.getBreed());
        }

        Animal b = new Cat("咪咪");
        for (Animal animal : new Animal[]{a, b}) {
            System.out.println(animal.speak());  // 同一调用，不同行为
        }
    }
}

抽象类与接口

抽象类用 abstract 声明，可以有字段、构造方法、已实现方法；接口定义能力契约，类可以实现多个接口，从而绕开单继承限制。接口中的方法默认是 public abstract，Java 8 起支持 default 与 static 方法。

InterfaceDemo.javaJAVA 17
interface Swimmer {
    void swim();

    default void floatOnWater() {
        System.out.println("漂浮中");
    }

    static Swimmer dummy() {
        return () -> System.out.println("假的游泳者");
    }
}

interface Flyer {
    void fly();
}

// 一个类可以实现多个接口
class Duck extends Animal implements Swimmer, Flyer {
    Duck(String name) { super(name); }

    @Override public String speak() { return getName() + "：嘎嘎"; }
    @Override public void swim() { System.out.println("鸭子游泳"); }
    @Override public void fly() { System.out.println("鸭子短距离飞行"); }
}

// 抽象类：适合共享状态与部分实现
abstract class Shape {
    protected String color;
    Shape(String color) { this.color = color; }
    abstract double area();
    double areaRounded() { return Math.round(area() * 100) / 100.0; }
}

class Circle extends Shape {
    private final double r;
    Circle(String color, double r) { super(color); this.r = r; }
    @Override double area() { return Math.PI * r * r; }
}

ObjectEnumRecord.javaJAVA 17
import java.util.Objects;

class User {
    private final String name;
    private final int age;

    User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // equals 与 hashCode 必须保持一致
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof User user)) return false;
        return age == user.age && Objects.equals(name, user.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    @Override
    public String toString() {
        return "User{name='" + name + "', age=" + age + "}";
    }
}

equals / hashCode 契约

基于哈希的集合（HashSet、HashMap）先用 hashCode 定位桶，再用 equals 比较。若两个对象 equals 为真，它们的 hashCode 必须相等；否则集合会出现“存进去却找不到”的诡异行为。作为键的对象不要在放入后修改参与哈希的字段。

// 错误：只重写 equals 不重写 hashCode
class BadKey {
    String id;
    BadKey(String id) { this.id = id; }
    @Override public boolean equals(Object o) {
        return o instanceof BadKey b && id.equals(b.id);
    }
}

Map<BadKey, String> map = new HashMap<>();
map.put(new BadKey("1"), "value");
System.out.println(map.get(new BadKey("1"))); // null ← 找不到

// 正确：同时重写，或直接使用 record（自动生成）
record GoodKey(String id) {}

泛型

泛型让代码在编译期获得类型安全，避免到处强制转换。Java 的泛型通过类型擦除实现：编译后类型参数被擦除为上界（默认 Object），因此运行时拿不到 List<String> 的真实类型参数。

Generics.javaJAVA 17
// 泛型类
class Box<T> {
    private T value;
    void set(T value) { this.value = value; }
    T get() { return value; }
}

Box<String> box = new Box<>();   // 菱形推断
box.set("hello");
String s = box.get();             // 无需强转

// 泛型方法
static <T extends Comparable<T>> T max(List<T> list) {
    T result = list.get(0);
    for (T item : list) {
        if (item.compareTo(result) > 0) result = item;
    }
    return result;
}

// 通配符
// ? extends T：上界，适合“读取”
static double sum(List<? extends Number> nums) {
    double total = 0;
    for (Number n : nums) total += n.doubleValue();
    return total;
}

// ? super T：下界，适合“写入”
static void addInts(List<? super Integer> list) {
    list.add(1);
    list.add(2);
}

// PECS 原则：Producer Extends, Consumer Super
// 只读数据用 extends，只写数据用 super

// 类型擦除带来的限制
// List<int> 不合法，必须用包装类型 List<Integer>
// 不能 new T()，不能 instanceof List<String>
// 泛型数组不能直接创建：new List<String>[10] 不合法
// 可以用 List<?>[] 或原始类型并配合注解抑制警告
不要忽略编译器的泛型警告 unchecked 警告通常意味着运行时可能发生 ClassCastException。使用原始类型（raw type）如 List 会丢失编译期检查，应尽量避免。

异常处理

Java 的异常体系以 Throwable 为根：Error 表示 JVM 级严重问题（如 OutOfMemoryError），通常不处理；Exception 又分为受检异常（Checked，必须捕获或声明）与运行时异常（RuntimeException，不强制）。

类别示例编译器是否强制处理
CheckedIOException、SQLException是：catch 或 throws
UncheckedNullPointerException、IllegalArgumentException否：通常表示编程错误
ErrorOutOfMemoryError、StackOverflowError否：一般不应捕获
Exceptions.javaJAVA 17
import java.io.*;

public class Exceptions {
    // 受检异常必须在方法签名声明，或内部捕获
    static String readFile(String path) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader(path))) {
            return reader.readLine();
        }   // try-with-resources 自动 close，即使抛异常
    }

    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException | NullPointerException e) {  // 多重捕获
            System.out.println("算术或空指针异常：" + e.getMessage());
        } finally {
            System.out.println("总会执行，用于清理资源");
        }

        try {
            String content = readFile("missing.txt");
        } catch (IOException e) {
            System.out.println("读取失败：" + e.getMessage());
            // e.printStackTrace();  // 生产环境用日志框架
        }

        // 主动抛出
        try {
            checkAge(-1);
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage());
        }
    }

    static void checkAge(int age) {
        if (age < 0) {
            throw new IllegalArgumentException("年龄不能为负：" + age);
        }
    }
}

// 自定义受检异常
class BusinessException extends Exception {
    BusinessException(String message) { super(message); }
    BusinessException(String message, Throwable cause) { super(message, cause); }
}

// 自定义运行时异常
class ConfigException extends RuntimeException {
    ConfigException(String message) { super(message); }
}
异常使用原则 不要用异常做流程控制；不要捕获后静默忽略；捕获后要么恢复、要么包装成更有语义的异常并保留 cause、要么记录日志后重新抛出。不要在 finally 中 return，它会吞掉异常。

Lambda 与 Stream

Java 8 引入函数式编程能力。Lambda 只能用于函数式接口（只有一个抽象方法的接口），java.util.function 提供了常用函数式接口。

Supplier<T>T get()提供值

// 自定义函数式接口
@FunctionalInterface
interface Calculator {
    int calc(int a, int b);
    // 只能有一个抽象方法；default/static 可以有多个
}
Calculator plus = (a, b) -> a + b;

Stream 管道

Stream 不是数据结构，而是数据处理的流水线：源 → 零个或多个中间操作（惰性）→ 终止操作（触发计算）。Stream 只能消费一次。

StreamDemo.javaJAVA 17
import java.util.*;
import java.util.stream.*;

List<String> words = List.of("Java", "C++", "Python", "Go", "Rust", "JavaScript");

// filter → map → sorted → collect
List<String> result = words.stream()
        .filter(s -> s.length() > 2)
        .map(String::toUpperCase)
        .sorted()
        .collect(Collectors.toList());

// 去重、限制、跳过
List<Integer> nums = Stream.of(1, 2, 2, 3, 4, 5)
        .distinct()
        .skip(1)
        .limit(3)
        .toList();                       // Java 16+

// flatMap：把多个集合摊平
List<List<Integer>> nested = List.of(List.of(1, 2), List.of(3, 4));
List<Integer> flat = nested.stream()
        .flatMap(List::stream)
        .toList();

// 统计与聚合
long count = words.stream().filter(s -> s.contains("a")).count();
int sum = IntStream.rangeClosed(1, 100).sum();
OptionalInt max = IntStream.of(3, 1, 4).max();
double avg = IntStream.of(1, 2, 3).average().orElse(0);

// reduce
int product = IntStream.of(1, 2, 3, 4).reduce(1, (a, b) -> a * b);

// 分组与分区
Map<Integer, List<String>> byLength = words.stream()
        .collect(Collectors.groupingBy(String::length));
Map<Boolean, List<String>> partitioned = words.stream()
        .collect(Collectors.partitioningBy(s -> s.length() > 3));

// 拼接
String joined = words.stream().collect(Collectors.joining(", ", "[", "]"));

// Optional：显式表达“可能没有值”
Optional<String> found = words.stream()
        .filter(s -> s.startsWith("P"))
        .findFirst();
found.ifPresent(System.out::println);
String value = found.orElse("默认值");
String upper = found.map(String::toUpperCase).orElse("");
Stream 的注意事项 中间操作是惰性的，没有终止操作就不会执行；同一个 Stream 不能重复使用；不要在流中修改外部可变状态；并行流 parallelStream() 只在数据量大、操作无状态且线程安全时才可能更快，默认用串行流。

多线程与并发

Java 从语言层面支持多线程。创建线程有两种传统方式：实现 Runnable（推荐，避免占用唯一的继承名额）或继承 Thread。更现代的方式是使用线程池与 ExecutorService。

ThreadDemo.javaJAVA 17
// 方式一：实现 Runnable（推荐）
Runnable task = () -> {
    System.out.println("运行中：" + Thread.currentThread().getName());
};
Thread t1 = new Thread(task, "worker-1");
t1.start();             // 启动新线程；直接调用 run() 只是普通方法调用
t1.join();              // 等待 t1 结束

// 方式二：继承 Thread
class MyThread extends Thread {
    @Override public void run() {
        System.out.println("MyThread");
    }
}
new MyThread().start();

// 竞态条件：共享可变状态需要同步
class Counter {
    private int count = 0;
    public synchronized void increment() { count++; }
    public synchronized int get() { return count; }
}

// 更轻量的原子类
import java.util.concurrent.atomic.AtomicInteger;
AtomicInteger atomic = new AtomicInteger(0);
atomic.incrementAndGet();

// 显式锁
import java.util.concurrent.locks.ReentrantLock;
ReentrantLock lock = new ReentrantLock();
lock.lock();
try {
    // 临界区
} finally {
    lock.unlock();      // 必须在 finally 中释放
}

// 线程池：不要为每个任务都 new Thread
import java.util.concurrent.*;
ExecutorService pool = Executors.newFixedThreadPool(4);
Future<Integer> future = pool.submit(() -> 1 + 2);
int result = future.get();          // 阻塞等待结果
pool.shutdown();                    // 不再接受新任务，等待已提交任务完成

// CompletableFuture：异步编排
CompletableFuture<String> cf = CompletableFuture
        .supplyAsync(() -> "hello")
        .thenApply(String::toUpperCase)
        .thenCombine(CompletableFuture.supplyAsync(() -> " world"),
                     (a, b) -> a + b);
System.out.println(cf.get());

// 并发集合
import java.util.concurrent.ConcurrentHashMap;
ConcurrentHashMap<String, Integer> cache = new ConcurrentHashMap<>();
cache.put("a", 1);
cache.computeIfAbsent("b", k -> 2);
工具作用说明
synchronized互斥锁简单可靠，锁粒度较粗。
volatile可见性 / 禁止重排序不保证原子性，不能替代锁。
AtomicInteger原子操作基于 CAS，适合计数器。
ReentrantLock显式锁支持可中断、超时、公平锁。
ConcurrentHashMap线程安全 Map分段/CAS，读多写少场景友好。
BlockingQueue阻塞队列生产者-消费者模型的常用基础。
虚拟线程（21+）轻量级线程由 JVM 调度，适合大量阻塞 I/O 任务。
死锁的四个必要条件 互斥、持有并等待、不可抢占、循环等待。实践中按固定顺序获取多把锁、使用超时 tryLock、减少锁嵌套，可以有效规避。

IO 与 NIO

Java IO 分为字节流（InputStream / OutputStream）与字符流（Reader / Writer）。文本文件应使用字符流并指定编码；图片、压缩包等二进制数据使用字节流。所有流都应放在 try-with-resources 中。

IoDemo.javaJAVA 17
import java.io.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.util.List;

// 传统字符流：适合逐行处理大文件
try (BufferedReader reader = new BufferedReader(
        new FileReader("demo.txt", StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

try (BufferedWriter writer = new BufferedWriter(
        new FileWriter("out.txt", StandardCharsets.UTF_8))) {
    writer.write("第一行");
    writer.newLine();
}

// NIO.2（Java 7+）：更简洁的 Files / Path
Path path = Path.of("demo.txt");
List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);
String content = Files.readString(path, StandardCharsets.UTF_8);
Files.writeString(Path.of("out.txt"), "内容", StandardCharsets.UTF_8);
Files.writeString(Path.of("out.txt"), "追加", StandardCharsets.UTF_8,
                  StandardOpenOption.CREATE, StandardOpenOption.APPEND);
boolean exists = Files.exists(path);
Files.createDirectories(Path.of("data/logs"));
try (var stream = Files.list(Path.of("."))) {
    stream.filter(p -> p.toString().endsWith(".java")).forEach(System.out::println);
}

// 缓冲字节流：复制二进制文件
try (InputStream in = new BufferedInputStream(new FileInputStream("a.png"));
     OutputStream out = new BufferedOutputStream(new FileOutputStream("b.png"))) {
    byte[] buffer = new byte[8192];
    int read;
    while ((read = in.read(buffer)) != -1) {
        out.write(buffer, 0, read);
    }
}
编码问题 不指定字符集时使用平台默认编码，跨平台易乱码。文本 IO 一律显式使用 StandardCharsets.UTF_8。Java 18 起默认字符集已是 UTF-8，但老代码仍需注意。

易错点与最佳实践

陷阱说明 / 正确做法
用 == 比较字符串用 equals / Objects.equals。
重写 equals 不重写 hashCodeHashMap/HashSet 行为异常；两者必须成对重写。
可变对象作 Map 键修改参与哈希的字段后无法查找。
自动拆箱 NPEInteger 为 null 时参与运算会抛 NullPointerException。
整数溢出用 Math.addExact 或 long；int 最大约 21 亿。
循环字符串拼接用 StringBuilder；编译器只优化简单场景。
金额用 double用 BigDecimal，并指定舍入模式。
catch (Exception e) {}吞异常导致问题难查；至少记录日志。
调用 run() 启动线程必须调用 start() 才会创建新线程。
忽略 InterruptedException捕获后应恢复中断标志 Thread.currentThread().interrupt()。
共享 SimpleDateFormat线程不安全；用 DateTimeFormatter。
遍历时删除集合元素用 Iterator.remove() 或 removeIf，否则 ConcurrentModificationException。
数组协变Object[] arr = new String[1]; arr[0] = 1; 运行时 ArrayStoreException。
可维护 Java 的实践 字段默认 private final；优先接口与组合；用 record 表达不可变数据；用 Optional 表达可能缺失的返回值；异常早抛、边界清晰；日志带上下文；并发代码优先用现成工具类而不是手写锁；为公开 API 写 Javadoc 和测试。
